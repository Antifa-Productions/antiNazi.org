Accessibility Statement

Last reviewed: July 27, 2026

Our Commitment

antinazi.org is committed to ensuring digital accessibility for all users, including those with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards to our literary archive and platform.

Conformance Status

This website aims to conform to the WCAG 2.1 Level AA guidelines. These guidelines explain how to make web content more accessible for people with disabilities and user-friendly for everyone.

Standard
WCAG 2.1 Level AA
Status
Partially conformant — known limitations are listed below.
Last audit
July 27, 2026

Measures Taken

We have implemented the following measures to support accessibility across the site:

  • Semantic HTML5 structure with proper landmark roles (<header>, <main>, <footer>)
  • Keyboard-navigable interface with visible focus indicators on all interactive elements
  • Descriptive page titles and metadata for screen reader context
  • Skip-to-content link for immediate access to main content
  • Responsive layout adapting to all viewport sizes and zoom levels
  • Respect for user color scheme preferences (light/dark mode via prefers-color-scheme)
  • No reliance on color alone to convey information
  • Alternative text provided for all informative imagery

Known Limitations

Some archived literary texts converted from plain-text sources (Project Gutenberg) may contain structural inconsistencies inherited from the original transcriptions. While we strive for semantic accuracy, some older texts may lack perfect heading hierarchies or footnote navigation.

We are actively working to remediate these issues as the collection grows and new texts are processed.

Technical Compatibility

This site is designed to be compatible with the latest versions of the following assistive technologies and browsers:

  • Screen readers: VoiceOver (macOS/iOS), NVDA (Windows), TalkBack (Android)
  • Browsers: Chrome, Firefox, Safari, Edge (latest stable releases)
  • Browser zoom up to 200% without loss of content or functionality
  • Operating system high-contrast modes
  • Keyboard-only navigation (Tab, Enter, Space, Arrow keys)

Report an Accessibility Issue

If you encounter an accessibility barrier on this site or find content that does not meet our standards, please let us know. We aim to respond to accessibility reports within five business days.

Email contact@antinazi.org

Please include the URL of the page and a description of the issue you encountered.

This statement was prepared based on the W3C Accessibility Statements model (EN 301 549).
